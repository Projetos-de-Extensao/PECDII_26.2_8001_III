# Projeto Back-End

**Código da Disciplina:** IBM8936

## Sobre

O projeto consiste no desenvolvimento de uma API Back-End para o GAAP
(Gestão de Atletas de Alta Performance) da PKZ Lab. A aplicação busca
centralizar agendamentos, alunos, profissionais e atividades, reduzindo
conflitos de horários e melhorando a organização da operação.

## Linguagens e tecnologias

- **Linguagens:** Python e Django
- **Tecnologias:** GitHub e Visual Studio Code
- **Pré-requisitos:** UX, Engenharia de Dados e POO
