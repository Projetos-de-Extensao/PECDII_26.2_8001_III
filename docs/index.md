# GAAP — Gestão de Atletas de Alta Performance

O GAAP é uma API REST desenvolvida para a PKZ Lab, escola de treinamento
esportivo que reúne atividades de treino, fisioterapia, psicologia e nutrição.
O projeto propõe centralizar a agenda e as informações operacionais da
instituição, substituindo controles dispersos e reduzindo conflitos de
horários, indisponibilidades e excesso de capacidade.

## Objetivo

Entregar um backend funcional, testado e documentado para apoiar a gestão de
estudantes, profissionais, serviços, espaços e atividades. O sistema considera
autenticação, autorização por perfil, agendamentos, registro de presença,
relatórios de treino e auditoria.

## Perfis de acesso

- **Administrador:** configura a operação, os cadastros e a agenda.
- **Treinador ou coach:** consulta sua agenda e registra atividades e
  relatórios de treino.
- **Profissional de saúde:** acessa os atendimentos relacionados aos serviços
  sob sua responsabilidade.

## Desenvolvimento

Este é um projeto acadêmico da disciplina IBM8936, desenvolvido com Python,
Django, banco de dados relacional, ORM, modelagem UML, testes automatizados,
Git e GitHub. A equipe utiliza RUP/UP e Kanban para organizar o trabalho.
