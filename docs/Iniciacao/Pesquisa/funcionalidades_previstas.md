### **Funcionalidades**

- Cadastro de alunos : Nome, idade, turmas, responsáveis, etc.
- Agenda de atividades : Registrar presenças, horários, etc.
- Controle de turmas : Criar, editar e organizar turmas em seus respectivos horários, verificar disponibilidade de horário dos professores.
- Dashboard de controle : Visualizar quantidade de alunos presentes, faltantes, pagantes e não pagantes, professores, etc.
- Busca e filtro de alunos : Localizar alunos por nome, turma, idade, etc.
- Relatórios de perfomance : Relatórios pessoais de cada aluno, para análise de evolução durante o tempo.
- Outros configurações gerais : Funcionalidades pontuais solicitadas pelo cliente.
